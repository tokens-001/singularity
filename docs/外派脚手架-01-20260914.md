## 1. 从 20+ 份实例里读出的格式规格（脚本的依据）

- **禁读清单有兩个世代**：早期是缩进多行式（逆向审-01/02、④⑤⑥、G/H/J/K/D/E'）；**最新三份（⑪⑫⑬）收敛为紧凑式**：`【硬约束·先读】**不要读**：` 起头，条目用 ` · `（U+00B7）连接，断行断在条目边界、行尾留 `·`，末尾 `。`。逐行算显示宽度（CJK=2），⑪⑬ 两份的断行位置与**行宽 90** 的规则逐字节吻合（⑫ 第二行是唯一的离群值，见 §验收一）。
- **条目集合 = 默认集合 − 本任务要读的**：⑬ 挡 `Desktop/要发的指令.md`，⑫ 要读它就没挡；H 要读 `OPEN.md` 就不挡 OPEN.md。⇒ 脚本用 `--allow` 表达"这条要读"，命中就**整条不放**或**降级为逐份枚举**。
- **整目录 vs 某几份**：整目录挡带注记——`ZCode审阅/（**全部**）`、`docs/*20260914.md（**全部归档**）`；开例外时降级为不带注记的逐份绝对路径（`--allow` 命中目录内部的某个文件时）。
- **归档条目**：`### ~~⑪~~ ／ 预检工具（**已发出、在跑** → 拟落 \`~/Desktop/ZCode审阅/预检工具-01.md\`）` + 原文围栏块，插在 `## 📄 已发出指令的原文` 节内、`## ①` 账表之前。`落点` 从原文 `【落盘】报告写到 \`...\`` 里解析。
- **待发文件结构**：抬头（用法 + `> 🆕 待发 N 个：…` 状态行）→ 每条 = `## ⑬ 标题` + 围栏原文，条目间 `---` 分隔。围栏内不会出现行首 `## `（脚本仍做了围栏感知，防未来撞上）。

## 2. 交付物与用法

`scripts/dispatch.py`（约 560 行，纯标准库）+ `scripts/test_dispatch.py`（21 条用例，全绿）。

```
python3 scripts/dispatch.py blocklist [--date YYYYMMDD] [--docs-days N] [--allow PATH ...] [--no-docs-note]
python3 scripts/dispatch.py header    [--original PATH] [--task "..."] [--baseline HASH] [--title ...] [--hard ...]
python3 scripts/dispatch.py move ⑫|12 [--apply] [--status "已发出、在跑"] [--pending PATH] [--archive PATH]
```

- `blocklist`：要粘的段走 **stdout**，扫描备注/提醒走 **stderr**（重定向不串味）。默认条目集与顺序照 ⑬ 实例；`--allow` 命中固定条目→整条不放；命中审阅目录或 docs 日期 glob **内部某份**→自动降级为**逐份枚举**（放行份不列）。docs 扫描按文件名日期归组，**只看文件名不读内容**；0908–0913 那些不在默认日期里的归档会逐日在 stderr 上点名，由你决定要不要 `--docs-days` 罩住。
- `header`：五字段骨架（原始件路径/任务/基线提交/硬约束/我的核实），全留（待填）；stderr 给建议文件名（`<主干>-<今天>.md`）。**绝不代写结论**。
- `move`：**默认 dry-run**，逐字打印要改成什么（删哪几行、抬头行前/后、插入哪段、改后行数），`--apply` 才写盘；写入前**再打印一遍**。重复归档有护栏（归档里已有同号即拒绝）。只改两条目行区间 + 抬头 🆕 行，**其余字节一律不动**；两个文件都在 git 里，`git diff` 可核、`git checkout --` 可整份还原。

## 6. 明说不自动化的事（及理由）

1. **抬头里「我的核实」的内容**：核实结论是人（你）核完才存在的事实，脚本写了就是编造。骨架 + 空位即止。
2. **归档账 ① 表的新行、② 在跑表、待发抬头的 🏃/已核完 行**：这些是**手写状态**（"抽核 3 条全真"这类话没法机械推导），脚本只打印「哪些行还提到 ⑫」的提醒，不代改。今晚归档文件里 ② 节"只剩 ⑥"与 ⑪ 在跑的矛盾就是这类行漂移的实例——机械改只会把矛盾写得更隐蔽。
3. **「可以读/例外」的正文措辞**（⑫ 式"本条的例外"）：任务语义相关，`--allow` 只负责把条目从清单拿掉并提醒你补一句。

## 7. 不确定 / 已知局限

1. **docs 日期 glob 的覆盖缺口**：默认只挡 `--date` 当天（照全部实例的惯例）。0908–0913 的 19 份带日期文件里既有输入（`静默except待修清单-20260913`，任务要读）也有产物（`外部答卷`），**按日期无法区分**，所以我没敢默认扩大，只点名报缺口。
2. **抬头格式**的样本是答卷-20260913 等近亲 + 你在指令里点名的五字段；0914 归档件本身禁读，字段标签若与最新实践有出入，改 `build_header()` 一个函数就够。
3. **⑫ 折行离群**（见 §3）。
4. 本窗口跑 `move --apply` 时，⑪ 窗口在并发改这个仓库（先 `validator.py` 后 `scripts/preflight.py`，都不是我改的）；两个指令文件这次没撞上，但**并发期跑写操作要留意**。
