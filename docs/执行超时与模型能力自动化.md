# 执行超时治理 + 模型能力自动化

> 2026-09-07~08，commit `ad3d633` + `9bca7cd` + `d7f08bc` + `f6dc646`。
> 记录「执行超时」的三处治理，和「模型能力数据从手写 → 自动化」的改造。

## 一句话结论

流水线跑不通有两个根子：一是 thinking 模型慢 + 轮数上限被硬抬到 15（超时），二是 QA 硬规则用错目录误杀合法产出（test_*.py）。修掉后，能力评级这种「纯展示、调度根本不看」的字段，从手写快照改成「零手写 + 一键基准」自动定档。

## 一、执行超时治理（`ad3d633`）

**根因**：`dispatcher.py` 把每模型 `max_turns` 强制 `max(current_max, registry_max, 15)`，硬下限 15 把 `models.toml` 里 deepseek-v4-pro 写死的 `max_turns=3`（thinking 模型 3 轮该搞定）抬到 15。thinking 模型 15 轮 × ~150s 直接撞 orchestrator 的 900s deadline。

三处改动：

| # | 改动 | 说明 |
|---|------|------|
| 1 | `max_turns` 尊重 registry | `max(..., 15)` → `current_max or registry_max or 8`，模型注册表里写的轮数生效 |
| 2 | `max_tool_turns` 5→3 | 压缩「反复测」空间 |
| 3 | 测试通过即停 | `openai_agent._tests_green`：run_command 跑测试且 exit=0 → 撤工具强制输出终答，治 thinking 模型「测过了还反复测」 |

## 二、QA 硬规则路径 bug（`9bca7cd`）

**根因**：`validator.py` 调 `_hard_diff_rules` 时把 cwd 硬编码成 `config.PROJECT_ROOT`（主仓库根），但 `changed_files` 是 worktree 里的文件。新建的 `test_fibonacci.py` 在主仓库根不存在 → 被 `no-delete-tests` 规则误判「测试文件已删除」→ QA 拒绝。

**影响**：任何写 `test_*.py` 的合法任务都会被误杀（之前的 hello.py 不匹配 `test_` 前缀才一直没暴露）。

**修法**：`validate()` 加 `cwd` 参数，`_exec.run()` 透传 worktree 路径。

## 三、scan 白名单通配（`d7f08bc`）

**根因**：`_is_major_model` 用精确版本号白名单（`^kimi-k2`、`^deepseek-v[34]`、`^glm-[45]`、`^gpt-5`…），厂家一升代际就漏——实测 kimi `/models` 返回 `kimi-k3` 但被过滤。

**修法**：精确版本 → 系列+数字通配（`^kimi-k\d+` 等），新代际不用改代码。

## 四、一键基准（`f6dc646`）

**背景**：确认调度器 `pick_agent` 选模型**完全不看 rating**（靠 project_lineup/role/用户排序/route_learner/default），rating 等是纯展示字段。那手写 `models.toml` 能力快照就是自找的负担。

**实现**：
- 新建 `_benchmark.py`：3 个金标准编码任务（fib 基础编码 / todo 结构化 / sql 数据查询，全零外部依赖），复用 `OpenAIAgentExecutor` 独立跑 + pytest 自动判定
- 评分定档写回：`rating`（通过率 S/A+/A）、`speed`（平均耗时）、`strengths`（通过任务标签）、`max_turns`（实测轮次+2）
- `cost`/`reasoning` 测不出（API 不返回价格、reasoning 是格式标记），保留手填
- 新端点 `POST /api/models/<id>/benchmark`（同步）；前端「跑基准」按钮 + 「未评测」标签
- 顺带修 latent bug：`add_model`/`model_update` 缺 `strengths` 形参会清空它

## 验证

- 289 测试绿（原 282 + `_summarize` 定档 5 例 + `add_model` strengths 2 例）
- 端到端：`deepseek-v4-pro` 跑基准 3/3 通过，rating=S、max_turns=7，写回 `models_custom.json` 正确
- fibonacci / todo 单任务真机跑通（47s/2 轮收敛，不撞 900s）

- kimi-k3 已扫出但欠费未测基准
