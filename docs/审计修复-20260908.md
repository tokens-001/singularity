# 安全审计 + Bug 修复

> 2026-09-08，commit `a301cbb`。5 个 agent 并行审计 2.7 万行源码，修复 P0 安全 4 项 + P1 功能 8 项 + P2 数据完整性 5 项。

## 一句话结论

审计发现两类问题：一是**安全默认值是错的**（无鉴权 + CSRF 回环豁免 + MCP command 可注入 = 打开网页即本机 RCE），二是**核心价值在静默失效**（constraints 类型错配让 QA gate 从未生效；cascade_accept 高置信结果被误判失败；审查失败 fail-open）。安全漏洞和"核心功能失效"全堵了，架构坏味道（拆大文件/合并重复实现）单开一批。

## 一、P0 安全（4 项）

| 漏洞 | 位置 | 修法 |
|------|------|------|
| CSRF 回环豁免 | `app.py:_guard_csrf` | 写请求带非本机 Origin 直接拒绝（浏览器跨站必带恶意 Origin） |
| 无鉴权读 `.env` 泄露 key | `app.py:api_project_file_content` | `realpath` 边界校验（`startswith` 前缀可被 `../` 绕过）+ `.env`/key/证书/`.git` 黑名单 |
| MCP command 注入 RCE | `_api_admin.py:mcp_server_add` | `_validate_mcp_command` 拒绝 shell 解释器 / `python -c` / 命令替换 |
| route_level 路径穿越 | `_api_tasks.py` + `_git_worktree.py` | API 层白名单 `[A-Za-z0-9_-]` + worktree 路径纵深清洗（防 `../` → 任意目录 chmod+rmtree） |

## 二、P1 功能（8 项）

| # | bug | 根因 | 修法 |
|---|-----|------|------|
| 1 | **QA gate 静默失效**（核心价值没在跑） | `constraints_checklist` 存成 dict 但字段/消费方按 `list[str]` 处理，`'; '.join()`/`c.lower()` 全 TypeError 被吞 | 统一 dict 契约 + `project.constraint_text()` helper（兼容历史 str） |
| 2 | **Anthropic 沙箱绕过** | 模块级 `_write_file`/`_run_command` 裸实现，`blocked_patterns` 参数根本没用 | 补 `_safe_path_at`/`_is_blocked_path_at`/`_is_dangerous_command_at`，与类方法同套检查 |
| 3 | cascade_accept 误重试 | 成功判定用 `validation.action=="pass"`，漏掉 conf≥0.75 的 cascade_accept（ok=True 但 action=retry） | `_exec.py`/`_task_runner.py` 改用 `batch.ok` |
| 4 | 安全审计 fail-open | 审计失败标 clean = "没审就当安全" | fail-closed：标 needs_fix + high finding 触发重试 |
| 5 | GATE3 打回空操作 | `fix_route=impl` 只改 phase 不重置 task → 打回→秒通过→再打回空转 | 重置 DONE 任务为 PENDING，真重跑 |
| 6 | 阶段推进停摆 | 队列无活任务时循环直接 break，`_auto_trigger_test_fix`（delivering/integrating/reviewing 推进）被跳过 | break 前补跑一次 |
| 7 | rollback 误删 | `git checkout -- .` + `clean -fd` 无差别删，可能抹掉开发者手动改动 | 破坏性操作前先 `stash push` 保护 |
| 8 | task_delete 反引用残留 | 只删文件不修 `children`/`task_ids` → 父任务 `maybe_complete_parent` 读不到子任务永久卡死 | 删除时清理两处反引用 |
