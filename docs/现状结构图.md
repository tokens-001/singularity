## 脚注：完整 Phase 链路

`project.py:19` 枚举 12 个 Phase。用户口头说的"四阶段"对应其中**有模型产出**的核心环节：

```
TEMPLATE → RESEARCHING → GATE1 → PLANNING → GATE2 → EXECUTING
         → INTEGRATING → REVIEWING → FIXING → GATE3 → DELIVERING → DONE
```

- **有模型产出**：RESEARCHING / PLANNING / EXECUTING / REVIEWING+FIXING（= 本文四阶段）
- **人工门禁**：GATE1 / GATE2 / GATE3
- **工程动作（非模型）**：INTEGRATING（worktree 合并+集成测试）/ DELIVERING（打包归档）/ TEMPLATE
