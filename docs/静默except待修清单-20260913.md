## ⚠️ 读之前必须知道的三件事

1. **这些是 ZCode 的建议，不是我核过的结论。** 每条动手前先按行号去看真代码，
   对不上就**按内容重新定位**（材料 23:32 生成，之后行号可能已经漂过）。
2. **`等级/危害` 是它自己填的**（A=不用管 / B=该出声 / C=结构问题 / D=吞错了异常），
   分数字越大越严重。**分高不等于结论对**，只是"值得先看"。
3. **判据是"分类器"，不是"修复器"** —— 它说的修法（`witness.warn` 带某 key）
   往往**漏掉三态**：有值 / 缺值(None) / 压根没发起。照抄会造出新的"两态混淆"。
