**所以本轮找的不是"测不到"，是"测出来了但是假的"**。逐条判下面这些形状：

  A. **没有断言** —— 函数里一句 `expect`/`assert` 都没有，或者断言在 `if` 里可能不执行

     `pytest.raises(Exception)` 太宽泛（连 `AttributeError` 都算过）；
     `assert result is not None or True`
  F. 🔴 **钉住错行为** —— 断言了某个 bug 的当前行为，且**注释/命名里看不出来**它是错的
