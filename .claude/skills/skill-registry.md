# Singularity Skill 注册表

两个 skill，一个学一个做。

## Skill 层（自动触发）

```
teach-me → 用户说"教我/怎么/讲讲/拆解" → 激活 → 编程/知识双轨
coding   → 用户说"写/改/修/bug/加功能" → 激活 → 确认意图→动手→收工
```

| Skill | 触发关键词 | 职责 |
|-------|----------|------|
| teach-me | 教、学、怎么、讲讲、带我、入门、理解、拆解、概念 | 教学——7种方法、双轨制、gotchas |
| coding | 写、改、修、代码、bug、报错、加功能、重构、查 | 编程——动手前先确认、改前先读、不动无关代码 |

## 冲突解决

两个都命中时（如"教我写这段代码"）→ teach-me 优先（教学流程 > 直接写代码）。

## Workflow 层（显式调用）

| 命令 | 用途 |
|------|------|
| `claude-ops` | D 层 Opus——架构设计、方向决策 |
| `python scripts/search.py "query"` | 搜索知识库 |
| `claude` | E 层 DeepSeek——日常主力（默认） |
