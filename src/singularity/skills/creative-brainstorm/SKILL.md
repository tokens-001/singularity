# Creative Brainstorm

当被要求提供创意方案时，遵循以下框架：

## 思维方式

1. **逆向思考**：从反方向看问题，找到新角度
2. **类比迁移**：从其他领域借思路
3. **极端推演**：推到极限看会发生什么
4. **组合创新**：把不相关的概念强行组合

## 输出格式

- 至少 3 个不同方向
- 每个方向列出核心idea+可行性评估
- 推荐最佳方向并说明理由
